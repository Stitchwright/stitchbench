# Notes (private)

The private side of StitchBench, StitchShop and StitchHub: the work log, plans, research, legal drafts and launch notes
that lived in the code repositories until they went public. Keep this repository private, and never copy anything from
it into a public repository, issue or pull request unless the owner chooses that item.

- `CLAUDE.md`: start here in a Claude Code session.
- `stitchbench/`: `HANDOFF.md` (the work log, read it first), `plans/`, `research/`, `legal/` (drafts for the lawyer),
  `round3/` (the security review, with findings still open), the launch checklists, `CODE_SIGNING.md`, `test-modes.md`,
  `CLAUDE.md` and `AGENTS.md` as they were, and `tools/` (scripts kept private).
- `stitchhub/`: the round-3 notes and the legal drafts with the reviewers' notes (the public copies have the notes
  taken out).
- `stitchsite/`: the website's internal README (deploying, placeholders, open decisions).

Paths in these notes that start with `docs/` refer to the old layout: `docs/plans/x.md` in stitchbench is now
`stitchbench/plans/x.md` here.

The complete history from before the switch is in the archived private repositories bwattendorf/stitchbench,
bwattendorf/stitchhub and bwattendorf/stitchsite.
