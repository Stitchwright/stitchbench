# The "About" box of each public repository

GitHub → the repository → the gear beside "About". Paste these.

**StitchBench**
- Description: Free, open-source software for sewing machine repair shops (StitchBench) and sewing and quilt shops (StitchShop): machines, factory specs, tickets, register and parts. Windows, hosted or self-hosted.
- Website: https://stitchbench.app
- Topics: sewing, sewing-machine, quilting, repair-shop, point-of-sale, inventory, nextjs, electron, postgresql, agpl

**StitchHub**
- Description: The free community hub for StitchBench and StitchShop shops: manual links, tech notes, parts cross-reference, marketplace and partner-shop channel.
- Website: https://hub.stitchbench.app
- Topics: sewing, sewing-machine, repair-shop, community, nodejs, postgresql, agpl

**StitchSite**
- Description: The website for StitchBench and StitchShop.
- Website: https://stitchbench.app
- Topics: nextjs, static-site, cloudflare-pages

For all three, untick Packages and Deployments under "Include in the home page" if they show nothing.
