# SiteSentrix

Free, open-source software for sewing machine repair shops and the sewing and quilt shops they work with.

| | |
| --- | --- |
| [**StitchBench**](https://github.com/{{ORG}}/StitchBench) | The repair bench for sewing, embroidery, longarm and industrial machine techs: every machine by model and serial, factory specs, tickets, invoices and parts. **StitchShop** is the same program set up for a sewing or quilt shop: the register, fabric by the yard, classes, and repairs sent to the shop's repair partner. |
| [**StitchHub**](https://github.com/{{ORG}}/StitchHub) | The free community hub the shops share: manual links, tech notes and photos, a parts cross-reference, a parts marketplace, and the private channel between partner shops. |
| [**StitchSite**](https://github.com/{{ORG}}/StitchSite) | The website, [stitchbench.app](https://stitchbench.app). |

Use them free on the shop's own PC or server, or let us host them for you: [stitchbench.app](https://stitchbench.app).

The programs are licensed under the GNU AGPL-3.0, the website's code under MIT. Found a security problem? Each
repository's SECURITY.md says how to report it privately.
